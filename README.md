# Buddypal

Buddypal is a companion app for Final Fantasy XI: a launcher for your characters and an in-game
assistant that plays alongside you.

- **Download:** the installer is published under [Releases](https://github.com/eLiidyr/buddypal/releases).
- **Guide:** see the [Wiki](https://github.com/eLiidyr/buddypal/wiki) for what Buddypal does and how to use it.

This repository hosts releases and the member wiki only; Buddypal's source is private.
